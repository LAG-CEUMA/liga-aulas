# Liga de Games Ceuma: aulas

Aqui aparece, semana a semana, **só o material já liberado**. O que ainda não foi liberado não existe neste repositório.

Cada pasta (`nivel-00/semana-01/`, ...) tem:
- `aula.md`: resumo da aula.
- `tarefa.md`: a tarefa de casa (também chega como Issue no seu repositório).

Seu repositório individual: `LAG-CEUMA/aluno-<seu-usuario>`.

Para atualizar no GitHub Desktop: **Fetch origin** e depois **Pull origin**.
